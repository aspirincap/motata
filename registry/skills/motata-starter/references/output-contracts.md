# Output Contracts

Use these lightweight artifacts to keep multi-phase work consistent.

## `product_intake`

Include when the task starts from a product, app, or landing-page URL:

- offer name
- destination type
- price anchor when available
- headline candidates
- value prop candidates
- CTA candidates

## `campaign_brief`

Include:

- objective
- offer
- target audience
- target geography
- recommended platform
- key message hypotheses
- test matrix
- required assets

## `asset_inventory`

Include:

- account or advertiser ID
- discovered pages, pixels, identities, media, or other promotable assets
- missing prerequisites
- notes on what is safe to use

## `execution_plan`

Include:

- platform
- target account
- token source
- read steps
- validation steps
- write steps
- expected outputs

## `review_report`

Include:

- scope
- time range
- top performers
- weak performers
- observed patterns
- likely causes

## `next_actions`

Include a short ordered list of:

1. immediate operational changes
2. validation or discovery tasks still needed
3. strategic changes for the next round
