# Motata 四阶段加固计划

范围：保持既有 CLI 兼容，优先修复安全与数据正确性，再落实安装交付、迁移恢复和分层。实施不调用真实广告 API，不发布，不操作真实账户。

## 1. 安全与数据正确性

- [x] 日志、URL、异常凭据脱敏与 inventory 跨页定位
- [x] bootstrap/报告成功、部分成功、失败状态和退出码
- [x] 分页截断元数据、币种隔离与严格指标降级
- [x] 有限请求超时及写入不确定性提示
- [x] live validation 显式确认及副作用矩阵

验收：秘密不出现在诊断中；失败不报成功；部分数据不冒充完整；跨币种不混加；dry-run 无写。

## 2. 可复现安装与发布

- [x] canonical registry/skills 源码与发布文件白名单
- [x] wheel/sdist/npm 内容检查和兼容性 JSON 包含
- [x] npm runtime 半安装恢复、Python 版本检查、调用目录与渠道识别
- [x] 默认禁网单测、CI 配置、临时环境干净安装验证
- [x] 版本、许可证声明与敏感文件检查

验收：干净交付不依赖本机私有目录；所有必要资源随包交付；安装可恢复。

## 3. 可恢复自动化

- [x] 版本化 job、原子 checkpoint、源目标 ledger、跨平台并发保护
- [x] resume 跳过已确认操作，不确定写入阻断并要求核验
- [x] 失败持久化、残留对象与安全清理计划
- [x] 中断、重复、损坏、并发等故障注入测试
- [x] 报告完整性契约

验收：恢复不会重复创建已确认对象；不声称跨平台恰好执行一次；清理不自动执行。

## 4. 模块化与产品契约

- [x] common 认证、配置、错误、校验与输出边界
- [x] Meta service/payload/preflight 不反向依赖 commands
- [x] TikTok CLI 注册、复制业务与 134 个 helper 抽离，保持命名空间兼容
- [x] 采集、诊断、打包后的 GMV Max HTML 渲染与远端写入边界
- [x] skills 单一来源、文件哈希与兼容性 snapshot 验证
- [x] 全量回归、产物与已知限制记录

验收：旧入口回归通过；业务模块不导入 CLI；README/help/skills 不再夸大产物。

最终执行记录见 `hardening-validation.md`。未验证的平台兼容性和真实 API 能力必须明确保留为限制，不因 mock 通过而声称线上验收。
